### Deskripsi Produk
AI Pengatur File adalah aplikasi manajemen file berbasis kecerdasan buatan yang membantu pengguna mengorganisir, mengganti nama, dan mengelola file secara otomatis dan efisien. Aplikasi ini menggunakan teknologi AI untuk memahami konten file dan memberikan solusi penamaan yang cerdas.

## FITUR UTAMA

### 1. Ganti Nama Massal (Bulk Rename)
**Deskripsi**: Rename ratusan hingga ribuan file sekaligus dengan AI
**Cara Kerja**:
- Upload atau pilih folder yang berisi file
- AI akan menganalisis konten setiap file
- AI memberikan saran nama yang relevan dan terstruktur
- User bisa review dan approve sebelum apply
- Proses rename dilakukan secara batch

**Keunggulan**:
- Hemat waktu hingga 80% dibanding manual
- Konsistensi penamaan di seluruh file
- AI memahami konteks dan konten file
- Support berbagai format file

**Use Cases**:
- Fotografer: Rename foto wedding/event dengan nama klien dan tanggal
- Arsivis: Standardisasi nama dokumen sesuai aturan ANRI
- Perusahaan: Konsistensi penamaan file project
- Personal: Organisasi foto keluarga dengan tanggal dan event

### 2. Folder Ajaib (Magic Folders)
**Deskripsi**: Organisasi otomatis file berdasarkan konten dan jenis
**Cara Kerja**:
- Pilih folder yang ingin diorganisir
- AI scan dan analisis semua file
- AI kategorisasi berdasarkan:
  * Jenis file (dokumen, foto, video, dll)
  * Konten file (invoice, kontrak, foto produk, dll)
  * Tanggal dan metadata
  * Custom rules yang user tentukan
- File otomatis dipindah ke folder yang sesuai

**Keunggulan**:
- Organisasi otomatis tanpa effort manual
- AI belajar dari pattern user
- Flexible categorization
- Real-time organization

**Use Cases**:
- Pisahkan foto per event/tanggal
- Organisir dokumen per jenis (invoice, kontrak, laporan)
- Sortir file download ke kategori yang tepat
- Backup organization

### 3. Template Penamaan Anda (Naming Templates)
**Deskripsi**: Buat dan gunakan template penamaan yang konsisten
**Cara Kerja**:
- User buat template dengan variables:
  * {date} - Tanggal file
  * {type} - Jenis file
  * {client} - Nama klien
  * {project} - Nama project
  * {counter} - Nomor urut
  * Custom variables
- Template bisa disimpan dan digunakan berulang
- AI bisa suggest template berdasarkan pattern

**Keunggulan**:
- Konsistensi penamaan di seluruh tim
- Compliance dengan standar perusahaan
- Reusable templates
- AI-assisted template creation

**Use Cases**:
- Standar penamaan dokumen perusahaan
- Format nama file untuk arsip nasional
- Naming convention untuk project development
- Personal organization system
